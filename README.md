# 笃行猫谱介绍页

这是为当前微信小程序项目新增的独立介绍页面，使用 Vite、React、Tailwind CSS 和 shadcn 风格组件构建。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署到 Vercel

1. 导入当前仓库。
2. 将 Root Directory 设置为 `intro-page`。
3. Build Command 使用 `npm run build`。
4. Output Directory 使用 `dist`。

## 部署到 Netlify

1. 导入当前仓库。
2. 将 Base directory 设置为 `intro-page`。
3. `netlify.toml` 已配置构建命令和发布目录。
